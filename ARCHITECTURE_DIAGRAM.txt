                    🔄 DATA FLOW EXAMPLE
                    (Verify Mode)

═══════════════════════════════════════════════════════════════════


     User places finger on sensor
               │
               ▼
     VerifyMode.cpp calls fpManager.verifyFingerprint()
               │
               ▼
     FingerPrintManager gets image from sensor
               │
               ▼
     FingerPrintManager searches database
               │
               ▼
     Match found? ──NO──► Show error on LCD, play error sound
               │
              YES
               │
               ▼
     Return ID and confidence to VerifyMode
               │
               ▼
     VerifyMode updates LCD (lcdManager.showFingerMatch())
               │
               ▼
     VerifyMode plays success sound (buzzerManager.playSuccess())
               │
               ▼
     Vote registered! Wait for next finger
